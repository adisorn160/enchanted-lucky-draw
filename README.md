# Enchanted Kingdom Lucky Draw Live

เว็บจับฉลากธีมปราสาทสำหรับงานครั้งต่อครั้ง แอดมินเปิดลิงก์ส่วนตัวแล้วกดสร้างห้อง จากนั้นกรอกชื่อหรือใช้ CSV และแชร์ลิงก์ให้เพื่อนเปิดบนมือถือหรือคอมพิวเตอร์ เลือกวงล้อหรือเลื่อนรายชื่อได้ ทุกหน้าจอใช้ผลและเวลาเริ่มเดียวกัน ระบบตัดชื่อซ้ำและกันผู้ชนะเดิมในห้องเดียวกัน หน้าผู้ชมเปิดดูได้อย่างเดียวและเห็นชื่อสั้นครบและชื่อยาวแบบปิดท้ายบางส่วน

ห้องมีอายุสูงสุด 8 ชั่วโมง และปิดพร้อมล้างข้อมูลได้จากหน้าแอดมิน ห้องเก็บรายชื่อและผลในหน่วยความจำของ Cloudflare Worker เท่านั้น เมื่อ Cloudflare พักหรือรีสตาร์ตห้อง ข้อมูลห้องอาจหายก่อนครบเวลา

## เผยแพร่

1. ใช้ Node.js 22 แล้วรัน `npm ci`, `npm test` และ `npm run build`
2. เผยแพร่ Worker เฉพาะงานนี้ด้วย `npx wrangler deploy` และตั้ง `ROOM_SERVICE_KEY` ด้วย `npx wrangler secret put ROOM_SERVICE_KEY`
3. ตั้งค่าบน Vercel เฉพาะโปรเจกต์ Enchanted Kingdom Lucky Draw แล้ว redeploy

| ตัวแปร | ค่า |
| --- | --- |
| `ROOM_SERVICE_URL` | URL ของ Worker |
| `ROOM_SERVICE_KEY` | คีย์ลับเดียวกับ Worker |
| `ADMIN_ACCESS_KEY` | ลิงก์แอดมินส่วนตัว `https://YOUR_SITE/#admin=RANDOM_KEY` และใช้คีย์สุ่มอย่างน้อย 24 ตัวอักษร |

เปิด URL ส่วนตัวจากค่า `ADMIN_ACCESS_KEY` เพื่อปลดล็อกหน้าสร้างห้อง ลิงก์ผู้ชมแชร์แยกจากลิงก์ส่วนตัว เบราว์เซอร์ที่สร้างห้องได้คุกกี้ HttpOnly สำหรับควบคุมห้อง ลิงก์ผู้ชมไม่มีสิทธิ์แก้ไขหรือส่งออกชื่อเต็ม ฝั่งเซิร์ฟเวอร์ใช้เวลาเริ่มร่วมกันเพื่อให้ทุกเครื่องเล่นแอนิเมชันรอบเดียวกัน แม้คำขอจะมาถึงคนละเวลา

CSV รองรับ UTF-8 และหัวคอลัมน์ `username`, `name`, `participant`, `ชื่อ`, `รายชื่อ` ถ้าไม่มีหัวตารางจะอ่านคอลัมน์แรก กดบันทึกหลังนำเข้า

## ทดสอบก่อนใช้งาน

เปิดห้องจากเครื่องแอดมินและเปิดลิงก์ผู้ชมอีกเครื่อง ทดสอบทั้งสองรูปแบบการสุ่ม รวมถึงการเข้าชมระหว่างสุ่ม กดรับทราบ และปิดห้อง
